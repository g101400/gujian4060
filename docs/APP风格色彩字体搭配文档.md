# APP 风格色彩字体搭配文档（古建景点打卡）

> 版本：v2.5.0　|　维护人：旺仔　|　更新：2026-09-12
> 说明：本APP所有菜单、页面、弹窗统一采用「浅蓝」主题，全部颜色/字体经由 CSS 变量（`:root`）集中定义，三份代码副本（aowei 源 / travel PWA / 发版快照）的 `css/style.css` 已 `diff` 校验完全一致。

---

## 1. 配色体系（CSS 变量，单一来源）

| 变量 | 色值 | 用途 |
|------|------|------|
| `--bg` | `#1a26f`→`#1a456f` | 主背景（深蓝），所有页面统一底色 |
| `--panel` | `#3f7fb8` | 面板/抽屉/弹窗背景 |
| `--panel2` | `#4f93c9` | 次级面板：输入框底色、图标卡底、菜单按钮底 |
| `--line` | `#6aa6d8` | 描边/分隔线（浅蓝），卡片与面板内边界 |
| `--txt` | `#f2f9fe` | 主文字（近白），保证在蓝底上的可读性 |
| `--muted` | `#d2e6f5` | 次要文字（浅蓝灰）：副标题、提示、计数 |
| `--accent` | `#6cc1ff` | 亮蓝强调：主按钮、图标高亮、选中态、FAB 主菜单 |
| `--accent2` | `#54e3b4` | 青绿次强调：确认/成功按钮（如「确定」「OK」） |
| `--danger` | `#ff5d6c` | 红：删除、危险操作、关闭按钮按下态 |
| `--warn` | `#ffb454` | 橙：警告/二次确认提示 |

**渐变约定**
- 顶栏：`linear-gradient(180deg, rgba(22,58,99,.96), rgba(22,58,99,.80))`（深蓝半透明 + 毛玻璃）
- 图标卡/菜单图标：`linear-gradient(180deg, var(--panel2), #2a6098)`
- 强调按钮：`linear-gradient(180deg, var(--accent), #3a9fe0)`

## 2. 字体规范

- **字族（全局）**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Microsoft YaHei", sans-serif`
- 中文优先回退到 `PingFang SC`（iOS/macOS）/ `Microsoft YaHei`（Windows），保证中文清晰无乱码。
- **字号梯度**：
  - 页面标题/抽屉头：`15–17px`（`font-weight:700`）
  - 正文/菜单项：`13–15px`
  - 次要/副标签（`.sub`）：`10–12px`（`color:var(--muted)`）
- **字重**：标题 700，按钮 600，正文常规。
- 数字/坐标等用等宽感知靠系统，不做特殊字体加载，避免离线缺字。

| 组件 | 风格要点 |
|------|----------|
| 顶栏 `.topbar` | 深蓝渐变 + 毛玻璃；标题左、搜索中、图标按钮右；查询/筛选按钮加亮蓝 `.accent` 醒目 |
| 抽屉菜单 `.drawer` | `--panel` 蓝底；菜单项 `.menu-btn` 左图标卡 + 文字 + 副标签；按下态变 `--panel2` |

| 浮动主菜单 `.fab-menu` | 右下角圆形亮蓝按钮，保证任何页面都能回到主菜单 |

## 4. 地图标记与交互视觉

- **建筑点位**：倒立水滴标记（drop marker）；筛选命中显示**绿色倒立水滴**，未命中为常规色。
- **筛选圈选**：命中多个建筑时用**蓝色虚线圆圈**（`.filter-circle`）刚好圈起全部命中，并 `fitBounds` 使整圈正好入屏。
- **单命中**：直接 `flyTo` 飞到该建筑。
- **零命中**：提示「没有符合条件的古建」。
- **退出交互**：每个弹窗均有「关闭 ×」；在地图上**三击空白**弹出「进入主菜单」选项，杜绝卡在当前页面。

---

## 5. 一致性原则（开发约束）

1. **禁止硬编码颜色**：所有新组件必须用上述 CSS 变量，不得写死 `#xxx` 以免破坏统一感。
2. **浅色文字配蓝底**：深蓝 `--bg`/`--panel` 上只用 `--txt`/`--muted`，不用深色字。
3. **圆角与圆角梯度**：卡片 14–16px、按钮/输入框 9–10px、图标卡 12–14px，保持柔和统一。
4. **高频操作醒目**：查询/筛选置顶且加亮蓝，删除等危险操作用红色明确区分。
5. **图标方块化**：所有来源选择/菜单图标统一 42–46px 圆角方块 + 亮蓝渐变，视觉一致。
6. **省内存**：地图标记/缩略图按需加载，大图仅在灯箱/导出时单张加载；导入流式解压逐张释放，避免 OOM。

> 本风格文档与 `css/style.css` 变量表一一对应，新增页面/组件时以本文档为准，确保三端（`aowei_win10/gujian_app`、`Claw/travel`、`Claw/travel/gujian_versions/*`）风格零漂移。
