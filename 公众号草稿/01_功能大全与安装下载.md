# 水利工程一张图 · 全功能详解与四端安装下载指南

「水利工程基础信息一张图」是一款**离线优先的地图类应用**，面向水利工程巡查、信息查阅与建筑物管理。它基于奥维互动地图导出的 `ovkmz` 数据，以天地图为底图，支持筛选、增删改、多照片、测距、导航、周边搜索、导入导出等一整套能力，并且**安卓 / Windows / 统信 UOS / 苹果 iOS 四端同源**，功能与风格完全一致。

本文按「基本功能 → 扩展功能 → 高级功能」分层讲解每一个菜单项，再给出四端安装与下载方式。

## 一、软件功能

### （一）基本功能

#### 1. 查询 🔍
- **功能及作用**：按关键词检索名称 / 类型 / 参数，命中结果在地图上高亮并圈选。查询用**绿色虚线圈**、筛选用**浅蓝虚线圈**，颜色区分一目了然。
- **如何使用**：顶栏「🔍 查询」按钮，或在搜索框输入关键词后回车（即 `doQueryConfirm`）。
  - 0 个符合 → 提示「没有符合条件的建筑」并保留关键词；
  - 1 个符合 → 立即飞到该建筑物；
  - 多个符合 → 倒水滴高亮标记 + 绿色虚线圈罩住全部 + 自动 `fitBounds` 居中，并显示「命中 N 个」徽标。
- **注意事项**：查询与筛选共用同一套条件集；查询命中多条后，底部会给出「进一步查询」智能建议（见高级功能）。
- **常见问题**：输入后没反应？确认是「回车」或点了查询按钮，仅输入不触发确认。

#### 2. 筛选 🎚️
- **功能及作用**：按「管理所 / 管理处 / 管理站 / 建筑物类型 / 历史关键词」组合筛选，实时显示命中数量与生效条件。
- **如何使用**：菜单「筛选」打开弹层 → 勾选芯片 → 顶部实时计数条「当前符合条件：N 个」→ 点「确认」。
  - 0 条提示；1 条定位；多条浅蓝虚线圈选 + 居中。
  - 筛选默认值会持久化（首次安装注入非「全部」种子，如「水库所」），启动即套用，避免全量渲染卡顿。
- **注意事项**：管理所名称已统一归一化（「温泉管理所」→「温泉所」，查询忽略「管理」二字）；管理站是管理所下一级单位，独立字段不合并。
- **常见问题**：找不到某管理所？权威清单 `CANONICAL_OFFICES` 已兜底全部 9 所（地下水源所、温泉所、龙山所、史山所、埝头所、水库所、北台上所、西田各庄所、潮河所）。

#### 3. 获取坐标
- **功能及作用**：在地图 / 标注 / 列表上右键，一键获取该点经纬度坐标，便于记录与上报。
- **如何使用**：显示界面右键上下文菜单 →「获取坐标」。
- **注意事项**：坐标为 CGCS2000（与天地图底图一致，无需偏移）。

#### 4. 添加照片
- **功能及作用**：为每个建筑物挂多张照片（正面 / 背面 / 侧面），支持批量导入压缩包照片。
- **如何使用**：
  - 添加 / 编辑建筑物时，在表单上传多张照片；
  - 菜单「批量导入照片」支持本地文件 / 百度网盘 / 夸克网盘，ZIP 与 7z/RAR 压缩包，递归搜索多层目录，并按「管理所 / 建筑物」智能匹配落盘。
- **注意事项**：大于 1.5MB 的照片导入时可压缩（默认 500K）；Android 端压缩最完整，桌面端（Win/UOS/iOS）走原图直读。
- **常见问题**：导入后照片显示为 0？多为 ZIP 中文名乱码或层级被截断——已通过 GBK/GB18030 探测与完整相对目录修复；仍异常请重试本地导入。

#### 5. 添加建筑物
- **功能及作用**：在地图上新增一个水工建筑物（点要素），填写名称 / 管理所 / 管理站 / 类型 / 自定义参数。
- **如何使用**：菜单「添加」→ 在地图落点 → 填写表单（支持自定义键值对参数）→ 保存。
- **注意事项**：建筑物类型采用规范清单 `CANONICAL_TYPES`（进水闸 / 节制闸 / 泵站 / 溢洪道 …），图例、筛选、编辑下拉一致；历史遗留的非规范类型在编辑时仍保留可选，不会被静默改写。

### （二）扩展功能

#### 6. 运行维护（设置类）
- **功能及作用**：数据管理、组织与类型维护、底图密钥、统计等「后台维护」能力，归在「设置」与信息菜单。
- **如何使用**：
  - **恢复初始数据**：清空本地改动，回到随包内置数据（见高级功能·初始化）；
  - **组织与类型管理**：增改管理所 / 管理站 / 类型，回写并同步建筑物；
  - **修改 / 添加天地图密钥**：本地自配密钥（三层回退：本地 → 环境变量 → 内置默认），保存后立即重建底图，密钥不明文显示；
  - **统计**：显示总数 / 点数 / 线数 / 含照片数，并按类型 / 管理所分组统计。
- **注意事项**：这些操作影响全部本地数据，增改组织 / 类型会逐个确认同步受影响建筑物。

#### 7. 导入导出（kmz / obj / 表格 / 照片）
- **功能及作用**：与奥维生态互通，批量搬迁数据。
- **如何使用**：菜单「传输与共享」组提供：
  - **导入 ovkmz / kmz / kml**：按名称 + 坐标合并；同名建筑弹「覆盖更新 / 保留现有 / 取消导入」三选一；同一文件按 SHA-256 二次导入提示「已导入过，是否覆盖」；
  - **导出标准 ovkmz**：含照片，重建 Folder 层级，保存到 `Download/水利工程一张图/`；
  - **导入 / 导出 ovobj · obj 坐标**：导入可选「单文件 / 整文件夹批量」，导出 obj 为文本坐标（建议优先用 obj，ovobj 导出为实验性）；
  - **导入 / 导出建筑物表格（CSV）**：导出可勾选列（名称 / 管理所 / 管理处 / 类型 …），格式与导入完全一致、APP 可导回；
  - **导出照片**：可选范围（全部 / 按管理所）、格式（ZIP / 7z）、目标（本地下载 / 网盘 / 分享微信·飞书·QQ）。
- **注意事项**：导出文件名带日期标识；按管理所导出照片时含「全部管理所」。iOS 端无原生桥，导出走下载、照片为只读展示。

#### 8. 测距 / 周边搜索
- **功能及作用**：现场量距与范围普查。
- **如何使用**：
  - **测距**：菜单「测距」→ 依次点地图 → 折线 + 各段 / 总距离 → 双击或按钮结束（测距模式禁用双击缩放）；
  - **周边搜索**：选中心建筑物 + 半径 → 地图画范围圆 → 结果按距离排序，可点定位（支持建筑 / 当前位置 / 地图选点三中心 + 类型筛选）。

### （三）高级功能

#### 9. 智能 AI 🤖
- **功能及作用**：大模型赋能的「智能查询 / 智能更新（补全）/ 智能纠错 / 知识库管理」，让内部资料也能被问答与补全。
- **如何使用**：设置「智能 AI 设置」配置自定义模型（OpenRouter / OpenAI 兼容 / 本地模型）、多模型与默认模型、自动调用策略（仅默认 / 失败切换 / 轮询）、连接测试、配置导入导出；菜单「智能 AI」进入三类操作。
  - 水利 / 感知为**内部资料**，默认「本地辅助」模式（不联网编造，仅基于本地记录问答 / 补全 / 存疑标注）；可逐次开启「联网在线查询」；
  - 古建为公共受众，默认联网；
  - 知识库（md + json 混合）支持读外部文件入库（pdf/xls/doc/csv/txt/md / 网页 / 公众号 / 微博）、导出 zip 备份、导入备份；
  - 查询历史按时间保存可复用 / 强制重查；结果美观排版 + 保存知识库「精简 / 不保存」；Hermes 自我学习循环异步沉淀经验。
- **注意事项**：内置三个 OpenRouter 免费模型预设（MiniMax M2.7 / GLM 5.2 / Nemotron 3 Nano Omni），默认 failover 策略（限流自动切换）；个人 API Key 写在本地 `ai_seed.js`，不进共享源码，请勿外泄。

#### 10. 初始化（恢复初始数据）
- **功能及作用**：一键清空本地所有增删改，回到发行内置数据，相当于「重置」。
- **如何使用**：设置 →「恢复初始数据」。
- **注意事项**：该操作不可撤销，执行前请确认已导出重要改动。

#### 11. 删除建筑物
- **功能及作用**：移除某个建筑物及其照片 / 参数。
- **如何使用**：点开建筑物弹窗 / 编辑页 →「删除」。
- **注意事项**：删除后同样不可撤销，建议先确认是否需保留。

## 二、软件特色与四端安装

**软件特色**：离线核心功能可用（无后端依赖）；四端同源、风格统一（CSS 变量驱动）；建筑物类型「颜色 + 形状」双维度区分；查询 / 筛选双圈颜色区分；每页退出按钮 + 三击空白防卡死；智能 AI 本地辅助 / 联网双模式。

### 安卓 Android
- 形态：原生 APK（aapt2 + d8 + zipalign + apksigner）。
- 安装：下载 APK → 允许「未知来源」→ 安装即可。当前版本 **V3.48**（构建 5090）。

### 苹果 iOS（PWA）
- 形态：PWA + 静态 HTTPS 托管（不打包原生）。
- 安装：用 Safari 打开托管地址 → 底部「分享」→「添加到主屏幕」，即类原生 App。
- 说明：依赖 HTTPS 托管；照片上传 / 网盘 / 系统分享等原生能力在 iOS 上降级为只读 / 不支持，查看类功能完整。

### Windows 11
- 形态：WebView2 原生壳（dotnet publish → WiX7 MSI + NSIS EXE）。
- 安装：双击 `V3.48_…_Win11_x64.msi` 或 `…_一键安装.exe`，按向导完成；需 .NET 8 运行时（EXE 便携版自带 bat 安装 / 卸载）。

### 统信 UOS
- 形态：浏览器壳（本地 http.server + 系统浏览器，零 PyQt6 依赖），纯 Python 构造 `.deb`，支持 **mips64el / loongarch64 / arm64 / amd64** 四架构。
- 安装：龙芯 3A4000 → `mips64el`；3A5000+ → `loongarch64`；飞腾 / 鲲鹏 → `arm64`；x86 → `amd64`。双击 deb 或用 `dpkg -i` 安装，每端独立端口，三端同机共存不冲突。
