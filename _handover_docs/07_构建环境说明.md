## 4. 必过门禁（一个逗号能打崩整个 App）

1. **改 `data.js` 双门禁**（v3.48 血案）：
   ```bash
   node --check <webroot>/data.js                       # 门禁1：语法
   node -e "读 data.js → JSON.parse(数组串).length"       # 门禁2：条目数断言
   # 基线：水利 SHUILI_DATA=557 / 感知 PERCEPTION_DATA=1125 / 古建 HERITAGE=1032
   ```
   缺逗号 → `window.<PROJ>_DATA` undefined → app.js 初始化即崩 → 所有菜单点开报「运行错误：script error」。
2. **改完源码必须真正出包**，并**从包内抽取核验**：`verify_rebuilt_data.py`（APK/iOS 抽 `assets/data.js`；deb 解 ar→xz；exe 用 7z 解；msi 核验源 + 版本标记）。源码修复时间戳晚于安装包构建时间戳 → 归档包仍是坏的。
3. **UOS deb 必过**：`python3 verify_myml_ar.py <deb>`（ar 头空格填充、mode 100644、tar 用 xz）。
4. **所有改动 `node --check` 通过后再推进**。
