# 四端功能对照表（v3.70 / v1.46 / v3.7.10 · 2026-09-11）

> 说明：三产品为**不同应用**（水利一张图 / 感知一张图 / 古建打卡），四平台实现方式存在合理差异，不做强求一致；本表用于说明「同一功能在各端的实现形态」。
> 归纳原则：**Android / Win11 / 统信 UOS = 原生应用**（原生 WebView / 原生浏览器壳，性能优先）；**iOS = PWA + 静态 HTTPS**（无原生壳）。

## 1. 平台实现形态

| 维度 | Android | Windows 11 | 统信 UOS | iOS |
|---|---|---|---|---|
| 形态 | 原生 APK（WebView 壳） | 原生桌面应用（WebView2） | 原生桌面应用（原生浏览器壳，零 PyQt6 依赖） | PWA + 静态 HTTPS |
| 安装包 | `.apk`（已签名 v1+v2+v3） | `.msi`（WiX7）/ `.exe`（NSIS） | `.deb`（4 架构） | 可托管 zip（添加到主屏幕） |
| 文件/照片 IO | 原生桥（pickFiles / exportPath / 压缩） | 浏览器下载 + 本地 HTTP 服务 | 浏览器下载 + 本地 HTTP 服务 | 浏览器下载 |
| 端口 | — | 7205 / 7206 / 7207（按产品） | 7205 / 7206 / 7207 | — |
| 内部版口令 | ✅ 首启口令门 | ✅ | ✅ | ✅（数据整体 AES 加密） |
| 公开版免除 | ✅ | ✅ | ✅ | ✅ |

### UOS 架构对照（已固化）
| CPU | 架构包 |
|---|---|
| 龙芯 3A3000 / 3A4000 | `mips64el` |
| 龙芯 3A5000 及以上 | `loongarch64` |
| 飞腾 FT2000 / 鲲鹏 | `arm64` |
| 其余（x86_64） | `amd64` |

### UOS deb 铁律（每次出包必过门禁）
1. `ar` 头成员名**空格填充，绝不 NUL**；
2. 成员 `mode` 必须 `100644`；
3. `data.tar` 用 **xz** 压缩；
4. 出包后必须 `python3 native-shell/verify_myml_ar.py <包>` 通过才允许交付。
