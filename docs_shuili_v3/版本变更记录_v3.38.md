## 二、Feature 1 — 筛选默认值持久化（三端）

- `SETTINGS` 增加 `defaultFilter`，持久化于各自 localStorage（shuili_settings / perc_settings / gujian_settings）。

- 启动 `render()` 前 `applyDefaultFilter()` 套用；序列化对 `Set` 字段通用，三端各自定义种子。

## 三、Feature 2 — 筛选结果可视化（已现成，回归确认）

## 四、Feature 3 — 知识库（Markdown+JSON 混合 + Hermes）

- 存储：`kb_<domain>` = {index:[{id,title,tags,type,source,ts,buildingId}], bodies:{id:md}}。**md 正文 + json 元数据索引**；csv 仅用于结构化表。
- 检索：小数据直喂 md；大数据关键词+轻量评分(BM25-lite)「先查 index 再读 body」。
- 设置菜单新增「知识库管理」三动作：①读取外部文件入库(pdf/xls/doc/csv/txt/md，best-effort 文本抽取) ②导出知识库备份(zip 打包 .md+.json) ③导入备份(zip)。

### 7.6 Win 出包关键坑（自我学习，已沉淀 MEMORY.md）
- ❌ 旧 `gen_win_msi.py` / `build_msi.bat` 依赖 WiX v3（candle/light/heat）+ 管理员，**本机不可用**；且前者 `ARCHIVE`/`PROJS` 指向过期目录与旧版本。**以 `gen_win_msi_wix7.py`(wix v7) 为准**。
- ⚠️ wix v7 **无 `heat` 子命令**，也无 harvest 开关 → 自己遍历目录生成 files 清单。
- ⚠️ **中文文件名**：`-out` 用中文名 wix 不写出文件；`File Source` 用中文 exe 名 wix 绑定**挂起**（无输出、无错误）。→ 暂存目录用 ASCII 路径，exe 改名 ASCII，安装目录 `Name` 仍可中文。
- ⚠️ `build_tree` 必须用 `node['dirs'].setdefault(p, ...)` 挂子目录；误用 `node.setdefault(p, ...)` 会把子目录挂到根导致 webroot 文件全丢（MSI 仅含根文件）。
- ⚠️ wix 构建 26MB exe 内嵌 cabinet 较慢（默认压缩 >2min 被前台超时杀），用 `-dcl none`（不压缩）秒级出包。
