## 六、本次实操沉淀（踩坑）

1. **Shell 环境**：WorkBuddy bash shim 会剥离 PATH 中 Git 的 coreutils（`ls`/`find`/`dirname`/`tail`/`head` 全部 not found）。
   解：每条命令前置
   `export PATH="/c/Users/admin/.workbuddy/binaries/PortableGit/versions/1.2.0/usr/bin:/c/Users/admin/.workbuddy/binaries/PortableGit/versions/1.2.0/bin:$PATH"`。
2. **gh 传参 glob**：外层 shell 会先对中文路径做 glob，导致 `gh release create` 报 "no matches found"，加引号无效。
   解：改走 Python `subprocess` 传参数列表（见 `github_staging_v376/github_publish_int.py`）。
3. **git push 被代理封锁**：本环境代理拒绝 git 对 `github.com` 的 CONNECT（502），`git push`/`ls-remote` 均失败；
   但 `api.github.com` 可达。**GitHub Pages 改用 Git Data API 提交**（blob→tree→commit→update-ref），
   见 `deploy_pub_pages_api.py`。
4. **公开包 AI 密钥泄漏风险**：`strip_internal.py` 的 `TARGETS` 只覆盖 `data.js`/`kb_building_seed.js`/`water_data.js`，
   **不含 `ai_seed.js`**。公开发布前必须额外把 `ai_seed.js` 替换为 `ai_seed.demo.js`（与上一版 3.75/1.51 一致）。
5. **公开派生必须可回滚**：`derive_public_v377.py` 用 md5 快照 + `try/finally` 保证 strip 与提版后一定还原，
   还原后逐文件比对 md5，不一致直接报错退出。
6. **批量删除守卫**：一次性删除 >50 个文件会触发 SAFE_DELETE_BULK_CONFIRM，改用**就地覆盖**而非 `rmtree` 重建目录。
