- **每次版本发布前**，将当前版本所有文件备份到 `backup/v{X.X}_{YYYY-MM-DD}/`

## v3.7（2026-08-15）优化迭代

> 本次按用户自查清单对「水利工程基础信息一张图」做体验与能力优化，未删除任何原有功能/菜单。

### 一、菜单图标与筛选图标（Req 1）
- 所有菜单图标统一改为**圆形色块**（主色-浅底白字），醒目且风格一致。
- 筛选图标由 `🔎` 改为 `🎚️`，与查询 `🔍` 明显区分（原两者均为放大镜，易混淆）。

### 二、筛选实时计数 + 结果框选（Req 2）
- 筛选弹层顶部新增**实时计数条**「当前符合条件：N 个建筑」，每勾选/取消一个芯片即时刷新。
- 点击「确认」后：
  - 0 条 → 提示「没有符合条件的选项」；
  - 1 条 → 立即定位该建筑物（沿用原逻辑）；
  - 多条 → 每个命中建筑替换为**倒水滴高亮标记**（琥珀色、尖端朝上），并以**蓝色虚线圈**（`#1e6fbf`，虚线 `7,8`）刚好罩住全部命中建筑，自动 `fitBounds` 适配视图。

### 三、批量导入照片（Req 3）
- 入口图标保持醒目；新增**来源选择**：本地文件 / 百度网盘 / 夸克网盘。
- 压缩包格式支持 **ZIP** 与 **7z/RAR**（原生 `unzipImages` 解压；7z/RAR 若原生不支持会提示改用 ZIP）。
- 网盘导入调用原生 `netdiskPick`（若未连接网盘账号则给出明确提示，请先用本地导入）。

### 四、导出照片（Req 4）
- 导出对话框可选：**范围**（全部合并 / 按管理所单独）、**格式**（ZIP / 7z）、**目标**（本地下载 / 百度网盘 / 夸克网盘 / 分享微信 / 飞书 / QQ）。
- 压缩包按管理所命名与分文件夹；新增原生 `shareFile` + `ShareProvider`，**分享到微信/飞书/QQ 真实可用**（以 content:// 规避 Android 7+ 的 file:// 限制）。
- 7z 格式在当前原生打包未支持时回退为 ZIP 并提示。

### 五、智能匹配确认（Req 4 智能匹配）
- 多匹配确认弹窗**默认勾选最匹配项**，并标注**置信度**（高匹配 / 较可能 / 待确认）与**推断范围**（管理所 / 类型），用户可一键确认或改选。

### 六、风格统一（Req 3）
- 顶栏/弹层头渐变、进度条、悬浮按钮等内联色统一引用 `:root` CSS 变量；刷新《07_APP风格色彩字体搭配》。
- 查询/筛选保持顶栏显眼；每页保留「退出本页」；三击空白处仍可呼出主菜单。
