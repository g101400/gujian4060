# 四端功能对照表（v3.41 / v1.17 / v2.9，2026-08-29）

> 对应需求：③ 三端四平台同步到小程序、考虑平台差异、给出四端对照表。
> 适用范围：水利工程一张图（V3.41）/ 水利感知项目一张图（V1.17）/ 古建景点打卡（V2.9）。
> 小程序（京引一张图 / jingyin）为独立 WeChat 工程，仅做**版本号 + 风格基线**对齐，不含 ovobj / 管理所 / ai_module 等原生与 AI 能力（本轮已对齐至 v3.41 基线）。

## 一、四端形态与构建对照

| 端 | 形态 | 构建链路 | 本次版本 | 原生桥 | 离线 |
|----|------|----------|----------|--------|------|
| **安卓 Android** | 原生 APK | aapt2 + d8 + zipalign + apksigner（`build_apk.sh`） | 水利 V3.41 / 感知 V1.17 / 古建 V2.9 | `window.Android`（Java 原生） | ✅ 全功能离线 |
| **Windows** | WebView2 原生壳 | dotnet publish → WiX7 MSI + NSIS EXE（`gen_win_msi_wix7.py` / `build_win_exe_nsis.py`） | 同上 | `window.Android`（`window.Desktop` 别名） | ✅ 全功能离线 |
| **统信 UOS** | PyQt6 原生壳 | `make_deb.py` → `.deb`（架构 mips64el，龙芯 3A4000） | 同上 | `window.Android` | ✅ 全功能离线 |
| **iOS** | PWA + 静态 HTTPS | `build_ios_zip.py` → 可托管 ZIP | 同上 | 无（纯静态只读，原生能力降级） | ⚠️ 依赖托管 HTTPS |

## 三、版本八处同步清单（本次已对齐）

1. `assets/version.json`（真相源）
2. `assets/app.js`（`APP_VERSION` / `APP_BUILD_DATE`）
3. `AndroidManifest.xml`（`versionCode` / `versionName`）
4. 6 个 webroot（`version.json` / `app.js` / `ovobj_bridge.js` 由 `bump_version.py` 同步）
5. `gen_win_msi_wix7.py`（`PROJS[].ver`，ASCII 暂存规避中文路径挂起）+ `build_win_exe_nsis.py`（NSIS EXE，含 app.ico 图标 + 开始菜单/桌面快捷）
6. `make_deb.py`（`PROJ[].ver`，**dict 形式，需手动同步**）
7. `build_ios_zip.py`（`PROJECTS[].file_ver/new_ver/readme_ver`，**dict 形式，需手动同步**）
8. 文档（`04_软件变更文档` / `05_版本历史与备份`）

## 四、已知差异与边界

- **iOS 无原生桥**：照片上传、网盘、系统分享等依赖 `window.Android` 的能力在 iOS 上降级为只读/不支持；其余查看类功能完整。
- **UOS 架构**：龙芯 3A4000 → `mips64el`；3A5000+ → `loongarch64`；FT2000/鲲鹏 → `arm64`；其余 → `amd64`（均经 `make_deb.py` `ARCH_MAP` 与 `ARCH=` 覆盖）。
- **小程序**：独立工程，仅版本/风格基线对齐，不在此四端构建链路内。
