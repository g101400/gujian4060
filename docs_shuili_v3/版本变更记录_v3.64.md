# 版本变更记录 v3.64（2026-09-08，内部版·加密+口令）

> 配套：感知 v1.40；古建 v3.7.7。
> 性质：**菜单 script error 根治 + 安卓 ovkmz 显示修复 + 知识库智能化内核 + 内部版防泄密（方案二：加密+启动口令 3305 + 公开仓库托管）**。
> 产物：`APK归档/测试包_20260908_v4_int/`（APK×3 门禁全过、UOS deb×12 ar 头校验全过、iOS PWA×3 + 公开×2 + 内部加密×2）。

## 一、本次需求

1. 根治「打开菜单报 getFavMenus is not defined」导致菜单整体不渲染（被 window.onerror 吞成「运行错误:script error」）。
2. 修复安卓 ovkmz 导入后显示不正常 / 不能放大。
3. 新增知识库智能化内核（4 个子菜单 + 强制联网）。
4. 内部版防泄密：数据加密 + 启动口令，内部 PWA 有可访问地址，且内部版可直接 GitHub 免登录升级。
5. 四端功能对照单与版本变更同步至本版。

## 二、核心改动

### E1 菜单 script error 根治

- **真因**：隐藏/收藏能力先在水利落地再移植感知/古建时，buildMenu 里 `getFavMenus()/setFavMenus()` 是裸标识符调用，移植端只在文件头挂 window 兜底、IIFE 作用域内无同名函数声明 → ReferenceError → 整个菜单不渲染。
- **修复**：三产品 canonical 的 IIFE 作用域内补齐局部函数声明（perc 补 getFavMenus/setFavMenus；gujian 补 menuTitleOf/getFavMenus/setFavMenus/toggleFavMenu，收藏数据映射到 `gujian_favorites_v32` 保证「快捷常用」只有一份）。
- 收藏/隐藏按钮继续保留二次确认。

### E2 安卓 ovkmz 导入显示修复

- **真因**：导入过程 busy 浮层与进度面板反复显隐，地图容器尺寸变化后 Leaflet 未收到 resize → 手势缩放失效、瓦片错位。
- **修复**：导入落库后显式 `map.invalidateSize()`（延迟 300ms 补一次），并自动 fitBounds 到本次导入要素范围（pad 0.2 / maxZoom 16），导入完成即可看到新数据。

### E3 知识库智能化内核（菜单「智能化内核」，`kb_core.js`）

1. **智能模糊检索**：标题/标签/来源 + 知识库片段混合排序（二元组 Jaccard + 单字覆盖 + 子串加成），支持错字、简写、别名，相似度百分比展示，可一键就地提问。
2. **提示词生成器**：6 套业务模板（巡检报告 / 维修方案 / 参数核对 / 汇报材料 / 隐患排查 / 培训要点），一键生成可直接投喂大模型的提示词，支持复制或「生成并提问」。
3. **AI 记忆 · Hermes**：对话记忆查看/清空 + 经验沉淀，沉淀条目自动被后续问答引用。
4. **存疑反向查询**：粘贴一段内容即可反查它出自哪些知识条目，并自动比对同项数值表述，列出「建议现场核实」的差异清单。
5. **强制联网开关**：开启后所有智能调用一律走在线大模型（本地知识库仅作上下文），断网时明确报错不再静默降级，并提供在线连通性自检（pingOnline）。
- 配套：`ai_module.js` 新增 `setOnline/isOnline` API；菜单注入 `KBCore.getMenuGroups()`。

### E4 内部版防泄密（方案二，本轮安全重点）

1. **内部 PWA 数据整体加密**：`data.js / kb_building_seed.js / ai_seed.js` 用 AES-256-GCM（PBKDF2-SHA256 派生，120000 轮）加密为 `secure/dat.enc.js`，明文文件已下线（站点返回 404 验证无泄露）；启动先弹口令门，口令正确才解密注入并加载应用（口令不在代码中明文存储，错则拒绝进入，通过一次本机记住）。
2. **内部 PWA 部署到公开仓库 Pages**（`shuili-yitu5090-sec`），解决私有仓库不支持 Pages 导致内部版没有在线地址的问题。地址：https://g101400.github.io/shuili-yitu5090-sec/
3. **应用内启动口令门**（`secure_boot.js`，仅内部版启用，渠道按版本号偶数判定）：内部版 Android / Win11 / 统信 UOS 启动需口令，公开版自动放行。
4. **GitHub 升级内部渠道切至公开 sec 仓库 Release**：免登录即可检测与下载，安装包本身仍受启动口令保护。
- 加密管线：`sec_crypt.js`（Node 加密）→ `make_secure_internal_pwa.py`（派生加密 zip）→ `secure_gate.js`（PWA 启动门）。
