# 版本变更记录 v3.45 / v1.21 / v3.3（2026-08-30）

## 一、本版背景

5 日智能化更新三端深度同步，把水利 v3.40→v3.45 在「设置菜单」「筛选」「导出表格」「ZIP 三级匹配」上的四块智能化升级按核心差异化同步到水利/感知/古建。

三图核心实体差异化：**水利 = 水工建筑物**、**感知 = 感知切切实设备**、**古建 = 古建**；水利感知共性是「局/管理处/所/站/段」5 级组织与「内部应用」AI 联网关，古建侧重「公共受众」AI 联网核实公开文物。本版不删除任何已有功能和菜单。

## 二、本版核心改动

### E1 设置菜单 - 修改/添加天地图密钥（三端共用）

- 新增菜单项「🗝️ 修改/添加天地图密钥」，进入设置面板。
- 三层回退：`localStorage（用户在「修改/添加天地图密钥」里改的）→ window.TIANDITU_TOKENS（index.html 环境配置）→ 内置默认`。
- 提供 32 位十六进制校验（非 32 位弹确认对话框，仍可强行保存）。
- 提供「📋 复制当前密钥」按钮（兼容 navigator.clipboard，老 WebView 回退 execCommand）。
- 提供「恢复内置默认」按钮。
- 保存后立即 `refreshTdtTileLayer()` 重建底图图层，**无须重启 App**。

### E2 筛选 - 管理处可多选 chip（按局→管理处→所顺序，前级筛掉的不进入后级筛选项）

- `filters.guanchu` 新增持久化字段，默认值「京密引水管理处」。
- `passFilter()` 新增 guanchu 判断：`if (filters.guanchu.size && !filters.guanchu.has(bG)) return false;`
- `openFilter()` 在管理所之上加「管理处」chip 行（generate by `guanchuOptions()` = 权威 5 项 + 自定义清单 + 数据实际值）。
- `filterActive()` / `filterDesc()` 同步加 guanchu 分支。
- `updateFilterCount()` 实时显示管理处 tag。
- `saveDefaultFilter()` 通过 `Object.keys(filters)` 自动序列化新字段（无需改 save/load）。
- 案例：勾选「京密引水管理处」会瞬间筛选掉潮白河管理处下的所有建筑。

### E3 导出建筑物表格 - 管理处列

- `exportTable()` 的 `baseCols` 在「名称」后面插入 `{ k: "guanchu", t: "管理处", checked: false }`，**默认不勾选**（保持兼容性）。
- `doExportTable()` 的 `labelMap` 增加 `"guanchu": "管理处"`，读取时若勾选则写入 `b.guanchu || getOrgDefaults().guanchu || ""`。

### E4 快捷常用 ⭐ 与点击隔离（v3.43 B5 已固化，本版确认感知/古建也已同步）

- v3.43 在 shuili 加的 `menu-fav` star `stopPropagation+preventDefault+防御性 return` 隔离机制，通过 v3.44/v3.45 端到端同步到感知/古建。
- 本版无新增代码，仅回归验证。

### E5 水利 zip 三级匹配 - longest-match level-aware（升级）

- `matchOrgInToken()` 重构：每层内按 value 长度倒序排序（长→短），保证「史山管理所」优先于「温泉管理所」、「北台上管理所」优先于「北台管理所」、「京密引水管理处」优先于「京密管理处」。
- 跨级仍按 `ju → guanchu → suo → zhan → duan` 顺序；命中后 `parentLevel = levels[li+1]` 供 folder 子匹配链式下钻。
- 案例：**`C:\Users\admin\Downloads\史山.zip` 内的 `IMG-6857.jpg` → 最匹配 史山所 的 三扬分水闸**
  - `token="史山.zip"` → token 扫描各级（ju/guanchu/suo/zhan/duan），最长匹配命中 "史山管理所"（len=4 → level=suo, parentLevel=zhan）
  - `z.folder=""`（裸放在 zip 根目录）→ 直接采用 zipName 命中的 scope
  - 后续 `classifyOne(it)` 在所有「史山所」的建筑物里按距离 + 名称匹配挑出"三扬分水闸"
- 案例：`C:\Users\admin\Downloads\北台上.zip` → "北台上管理所"（len=5）优先于较短的"北台上"（len=3）。
- 古建版 `matchOrgInTokenV33` 同步实现：key=spot/area/sub/point/tag，对应水利 5 级组织 key=ju/guanchu/suo/zhan/duan 同形不同名。

### E6 古建/感知 placeholder 文雅化（确认已无残留）

- `ai_module.js` 三态 placeholder 已通用化：
  - 古建：`如：颐和园佛香阁的建筑年代与结构特点`（CFG.appName.indexOf("古建") 命中）
  - 感知：`如：北台上液位传感器最近一次监测数据`（CFG.appName.indexOf("感知") 命中）
  - 水利：`如：龚庄子进水闸的设计流量与结构特点`（水利的核心实体，无问题）
- 三端 ai_module.js 完全一致，古建/感知不再出现"龚庄子进水闸"提示。
- 用户实测反馈「龚庄子进水闸」是水利的关键词（说明水利用户用得很对），本版确认古建已不显示。

### E7 每页退出按钮 + 三击空白呼主菜单（v3.15+v3.6 已固化，本版确认三端回归）

- 每个 sheet 系列 panel 的 foot 都保留「✕ 退出本页」按钮。
- `closeTopLayer()` 监听任意三击空白（间隔 < 700ms），先关最上层弹层，再呼出主菜单；传输/忙提示期间不响应，防误触。
- 公交化（水利/感知/古建）同款。

### E8 端到端同步（v3.40+v3.41+v3.42+v3.43+v3.44 在古建/感知的所有智能化升级）

- 水利 v3.45 = v3.44 + E1+E2+E3+E5（4 项增量）。
- 感知 v1.21 = v1.20 + E1+E2+E3+E5（保留 v1.20 已修的 cp 失误遗物 + 核心=感知设备的 subsystem 元数据）。
- 古建 v3.3 = v3.2 + E1（tdtKey 设置复用水利/感知同款）+ E5（古建版 zip longest-match +5 级组织 key=spot/area/sub/point/tag）。
