## 二、Feature 1 — 发行前预生成知识库（三端）

- 构建期生成 `assets/kb_building_seed.js`（`window.KB_BUILDING_SEED` 全局数组）：shuili 557 条 / perc 1125 条 / gujian 1032 条，随安装包内置。
- `ai_module.js init()` 时 `mergeSeed()` 按 buildingId 去重合并进 `kb_<domain>`，不覆盖用户后续增改；无种子文件时回退运行时 `seedBuildings()` 播种。
- `buildBuildingBody()` 扩展通用字段：子系统（perc）/ 所属地、朝代、级别、简介、特点（gujian）。
- index.html 在 `data.js` 后引入种子脚本（三产品 × 各 webroot 全部接线）。

## 三、Feature 2 — 查询融合引擎（智能AI × 知识库）

- 同一查询路径：先查本地 KB（命中标注 **🔒本地**）→ 未命中且允许联网 → LLM 检索（标注 **🌐在线**）→ 未命中且离线 → 友好提示。
- 知识库管理查询增加**确认按钮**；全程 `Promise resolve` 不 reject、异常转友好结果——根治「运行错误: script error」（window.onerror 兜底误报）。
- 智能AI 查询同引擎同标注；查询历史（30 条）可复用。

## 四、Feature 3 — 知识库网页入库 + 补丁可编辑

- 知识库管理新增「读取网页入库」：普通网页 / 微信公众号文章 / 微博，fetch 抽取正文入 KB；受目标站跨域限制失败时提示改用复制粘贴入库。
- 智能更新补丁预览由只读文本改**可编辑输入框**，应用前可逐字段修改。

## 五、Feature 4 — 筛选与名称体系（水利专项）

- **照片状态卡顿根治**：`openFilter` 照片 chip 点击原实现 `cPh.innerHTML = photoChips()` 重建 DOM 丢绑定 → 改 `genBody` 事件委托 + 仅切换 `≥N` 输入显隐 + `scheduleRender` 节流，不再全量 `render()`。
- **管理所/管理站手动增改**：筛选面板「＋添加 / ✎改名」；持久化 `customOffices/customStations`；改名对受影响建筑物**逐个确认**后同步；添加/编辑建筑物表单的管理所/管理站改下拉（读持久化记录）。
- **关键词历史**：筛选关键词保存最近若干条，可展开/收起。

## 六、Feature 5 — 周边搜索与导出增强（水利专项）

- 周边搜索中心三种方式：**选建筑物 / 当前位置**（geolocation，MainActivity 已启用定位授权；不可用时引导改地图选点）/**地图选坐标**（nearbyPickMode 一次性拾取）；新增**按周边建筑物类型**筛选。
- 导出建筑物表格 / 照片：管理所选项 = `officeOptions()`（权威 9 所 + 实际出现），按建筑物**自动匹配**其管理所；无照片的所标注。
- 导出文件名可编辑（非法字符清洗）：照片 zip/7z、建筑物 CSV、**ovkmz**（新增导出前对话框：范围+文件名）、**ovobj**（`exportOvobj(fileName)` 带名导出）。
