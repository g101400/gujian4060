## 1 引言

### 1.1 目的
本文件描述「水利工程基础信息一张图」Android 应用的软件需求，涵盖功能需求、非功能需求、约束条件和接口要求。适用于开发、测试、验收及后续维护。

### 1.2 范围
本应用为离线 WebView 地图应用，面向水利工程的现场巡查、信息查阅、建筑物管理。基于奥维互动地图导出的 `.ovkmz` 数据，以天地图为底图，支持筛选、增删改、多照片、测距、导航、周边搜索、导入导出等功能。

### 1.3 术语
| 术语 | 含义 |
|------|------|
| ovkmz | 奥维互动地图导出的 ZIP 格式（含 doc.kml + ovatta 照片） |
| 天地图 | 国家测绘地理信息局在线地图服务 |
| WebView | Android 内嵌浏览器组件 |
| Leaflet | 开源 JavaScript 地图库 |
| CGCS2000 | 2000 国家大地坐标系 |

## 2 总体描述

### 2.1 运行环境
- **操作系统：** Android 8.0+（minSdk 21，targetSdk 34）
- **硬件：** 5.0 寸以上屏幕，2GB+ 内存，50MB 可用存储
- **网络：** 在线底图需联网；离线模式下标记/线/数据仍可用
- **权限：** 定位（可选）、存储（导出）、文件访问（导入/照片上传）

### 2.2 用户特征
- 水利工程巡查人员：现场查看建筑物位置、参数、照片
- 管理人员：在办公室筛选、统计、查阅
- 数据维护人员：增删改建筑物信息、导入导出 ovkmz

### 2.3 约束
- 纯前端应用，无后端服务器
- 数据存储在 localStorage，上限约 5MB
- 天地图 Token：浏览器端 `61691764ff68bf341c4c9c4770b24b5f`
- 天地图 Token：服务器端 `d258e3622cb1755b59a59e4b7ac6d96e`（本应用不直接使用）
- 坐标系：CGCS2000（与天地图底图一致，无需偏移）

## v3.7（2026-08-15）优化迭代

> 本次按用户自查清单对「水利工程基础信息一张图」做体验与能力优化，未删除任何原有功能/菜单。

### 一、菜单图标与筛选图标（Req 1）
- 所有菜单图标统一改为**圆形色块**（主色-浅底白字），醒目且风格一致。
- 筛选图标由 `🔎` 改为 `🎚️`，与查询 `🔍` 明显区分（原两者均为放大镜，易混淆）。

### 二、筛选实时计数 + 结果框选（Req 2）
- 筛选弹层顶部新增**实时计数条**「当前符合条件：N 个建筑」，每勾选/取消一个芯片即时刷新。
- 点击「确认」后：
  - 0 条 → 提示「没有符合条件的选项」；
  - 1 条 → 立即定位该建筑物（沿用原逻辑）；
  - 多条 → 每个命中建筑替换为**倒水滴高亮标记**（琥珀色、尖端朝上），并以**蓝色虚线圈**（`#1e6fbf`，虚线 `7,8`）刚好罩住全部命中建筑，自动 `fitBounds` 适配视图。

### 三、批量导入照片（Req 3）
- 入口图标保持醒目；新增**来源选择**：本地文件 / 百度网盘 / 夸克网盘。
- 压缩包格式支持 **ZIP** 与 **7z/RAR**（原生 `unzipImages` 解压；7z/RAR 若原生不支持会提示改用 ZIP）。
- 网盘导入调用原生 `netdiskPick`（若未连接网盘账号则给出明确提示，请先用本地导入）。

### 四、导出照片（Req 4）
- 导出对话框可选：**范围**（全部合并 / 按管理所单独）、**格式**（ZIP / 7z）、**目标**（本地下载 / 百度网盘 / 夸克网盘 / 分享微信 / 飞书 / QQ）。
- 压缩包按管理所命名与分文件夹；新增原生 `shareFile` + `ShareProvider`，**分享到微信/飞书/QQ 真实可用**（以 content:// 规避 Android 7+ 的 file:// 限制）。
- 7z 格式在当前原生打包未支持时回退为 ZIP 并提示。

### 五、智能匹配确认（Req 4 智能匹配）
- 多匹配确认弹窗**默认勾选最匹配项**，并标注**置信度**（高匹配 / 较可能 / 待确认）与**推断范围**（管理所 / 类型），用户可一键确认或改选。

### 六、风格统一（Req 3）
- 顶栏/弹层头渐变、进度条、悬浮按钮等内联色统一引用 `:root` CSS 变量；刷新《07_APP风格色彩字体搭配》。
- 查询/筛选保持顶栏显眼；每页保留「退出本页」；三击空白处仍可呼出主菜单。
