# 版本变更记录 v3.49 / v1.25 / v3.7（2026-09-02）

## 一、本版背景

v3.48（2026-09-01）完成了「UOS 启动诊断」系列根治（T-041~T-047e）：本地服务强制 `no-store` 防缓存、启动器/安装日志每次都写、日志权限不被递归 `chmod` 破坏（铁律-UOS5~9）。用户真机复现确认 3.48 **安装正常、能正常打开、日志也正常出现**（`launch_err.log` 含 `serving version= 3.48` + `no-store=on` + `HTTP=200`，user=guest）。

基于这一稳定基线，本版做**两件事**：

1. **把「启动日志诊断」能力智能同步到全平台并让日志版本号自动跟随版本**：保留 UOS 既有诊断（server.py / 启动器 / postinst 已落地），新增网页层 `logRuntime()`——三端 canonical app.js 启动时把「产品名 + 版本号 + 构建日期 + 平台」写入 `console.log` 与 `localStorage["yitu_runtime_log"]`，版本号直接读 `APP_VERSION`（随 `version.json` 自动更新）；UOS 端 `server.py` 的 `_startup_log()` 兜底证明浏览器加载的是当前版本。这样将来任一端打开，日志里的版本号会自动跟着版本走，便于快速定位「装的是哪版」。
2. **水利「信息与帮助」菜单内容全量更新 + 三图同源同步**：四端功能对照单、版本变更补到最新；子菜单「帮助」改名为「功能介绍」（原名易与「关于」混淆），并把历次新增功能（筛选持久化、快捷常用长按、智能AI、知识库、运行维护、设置-天地图密钥、错误日志排查等）全部收进「功能介绍」正文；古建、感知参照同步同样改名与内容。

三图核心实体差异化保持不变：**水利 = 水工建筑物（557 条）**、**感知 = 感知设备（1125 条）**、**古建 = 古建景点（1032 条）**；水利/感知为内部应用（AI 默认关），古建为公共受众（AI 默认开）。

本版为**文档与诊断增强小版本**：不删除任何已有功能/菜单，按「水利 v3.49 / 感知 v1.25 / 古建 v3.7」同期发版，四平台 + 微信小程序同步。

## 二、本版核心改动

### F1 全平台启动诊断 logRuntime（三端 canonical，版本号自动跟随）

- 新增 `logRuntime()`（注入三端 canonical app.js 末尾、`/* 工具 */` 段前）：
  - 解析 `navigator.userAgent` 判定平台：iOS / Android / Win / UOS / Web；
  - 取产品名（`window.SHUILI_META.appName` 或 `APP_NAME`）；
  - 组装诊断行 `▶ 启动 <name> <APP_VERSION> (build <APP_BUILD_DATE>) platform=<plat>`，`console.log` 输出；
  - 同时写入 `localStorage["yitu_runtime_log"]`（数组，最多保留最近 20 条，含 `ts/v/d/p`），并挂 `window.__LAST_RUNTIME__`；
  - 版本号直接读 `APP_VERSION`/`APP_BUILD_DATE`（来自 `version.json` 注入），**版本一升、日志里的版本号自动跟着变**——满足「日志中记录版本号也跟着更新」。
- 注入方式：`Edit` 直接在三端 `app.js` 末尾追加，`node --check` 三端全过。
- UOS 端既有诊断不丢：①`make_deb.py` 的 `server.py` 自带 `no-store` + `_startup_log()`（写 `<pkg>/launch_err.log`+`<pkg>/server.log`+`$HOME/.cache/<pkg>/launch_err.log` 三处）②启动器 `exec >>launch_err.log` + `[ ! -w "$LOG" ]` 回退 `$HOME/.cache` ③postinst `chmod 755 -R` 之后补 `chmod 666` 两日志（铁律-UOS9）。`logRuntime()` 是**网页层**诊断，与 UOS 层诊断互补，覆盖 Android / Win / iOS 三端同源 app.js。

### F2 子菜单「帮助」改名「功能介绍」+ 正文补全（三端）

- 水利 / 感知 / 古建 `showHelp()` 标题改为 `功能介绍`，正文扩充为最新功能清单（16 项级）：
  ①筛选默认值持久化 ②管理所/组织类型 ③照片落盘/网盘导入/分享 ④ovobj 导入导出 ⑤导出建筑物表格/照片 ⑥智能AI（设置+助手）⑦知识库（读/导出/导入）⑧查询（普通+智能）⑨快捷常用长按收藏 ⑩智能AI进一步操作 ⑪知识库增强 ⑫运行维护（日志/缓存）⑬设置-天地图密钥 ⑭关于/版本 ⑮四端功能对照 ⑯错误日志排查。
- 菜单两处同步改名（主菜单 `add("信息与帮助","❓","help","功能介绍")` 与子菜单 `{k:"help",t:"功能介绍"}`），旧「帮助」残留经 grep 全清（三端 `功能介绍 rename present: True` / `旧「帮助」菜单残留: False`）。

### F3 四端功能对照单 + 版本变更补到最新（水利）
