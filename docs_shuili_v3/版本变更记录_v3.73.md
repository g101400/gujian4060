## 一、本版定位

v3.73 由内部 v3.72 **同批派生**，**功能与内部版完全一致**，差异只在两点：

1. **数据脱敏**：`data.js` / `kb_building_seed.js` 换为 `*.demo.js`
   （建筑物名称取自著名真实水利工程、坐标与设计参数均为**示例值**，不含单位内部资料）；
2. **密钥剥离**：`ai_seed.js` 换为无密钥演示版（`apiKey: ""`）。

> 通道机制：`APP_VERSION` 末段为**偶数=内部版**、**奇数=公开版**。
> v3.73 为奇数 → `getReleaseChannel()` 返回 `public` → `secure_boot.js` 口令门**自动放行（免密）**。
