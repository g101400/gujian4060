# 水利工程基础信息一张图 —— 版本变更记录 v3.68（内部版，2026-09-10）

> 同步版本：感知 v1.44 / 古建 v3.7.9；公开派生版：水利 v3.69（演示数据，免密）。
> 产物目录：`APK归档/测试包_20260910_v6_int/`（APK×3、UOS deb×12、Win MSI+EXE×3、iOS PWA 明文/加密/公开）。

## 一、口令提示优化
- 内部版所有对话框与提示语**不再出现具体口令数字**，只提示「默认口令即开发者分机号」；忘记口令提示联系开发者（分机号）协助重置。
- 口令本身不变（仍为开发者分机号），校验仍走 AES-256-GCM + PBKDF2-SHA256（12 万次迭代），不落明文。

## 二、菜单防误触
- 子菜单标题与右侧「隐藏 / 收藏」按钮的间距由 6px / 8px **拉大到 26px / 14px**，点击区同步放大（padding 6px 10px），有效避免想点子菜单却误触按钮。

## 三、建筑物导入 / 导出 CSV 兼容（重点修复）
- **导入报「未找到名称列」的根因修复**：
  - 编码自动识别（UTF-8 BOM / 合法 UTF-8 / GB18030）——奥维互动地图导出的 CSV 多为 GBK，此前按 UTF-8 读取导致表头乱码。
  - 分隔符自动识别（, ; Tab），不再把参数串里的 `|` 误当分隔符。
  - 名称列智能匹配：名称 / 建筑物名称 / 设备名称 / 名称（name）/ 标题等，并支持兜底取首列。
  - 兼容奥维导出的 **Comment 列**（参数条目 `|` 分隔，键值 `键 : 值`）与本应用导出的 **comment 列**（`|` 或 `;` 分隔），并支持「每个参数一列」的宽表；属性随条目一并入库并在详情页显示。
- **导出建筑物 CSV**：第 8 列表头「参数说明」改为 **comment**，参数条目分隔由 `; ` 改为 `|`，导出→导入完全往返。

## 四、ovkmz 导出备注分隔
- 建筑物 `<description>` 改为「**键 : 值**」条目之间以 **| + 换行** 分隔，奥维气泡与本应用导入均可正常解析。

## 五、本地向量智能化内核（kb_vector.js，全新）
菜单「智能化内核」新增 6 项，全部**离线可用**（哈希 TF-IDF + 余弦相似度，无需联网、无需向量数据库）：
1. **智能反查建筑物**：用自然语言/参数描述反查条目，如「宽度3米的闸门」「设计流量70的进水闸」「两米宽的公路桥」，返回名称 + 相关度 + 命中的关键参数。
2. **统计汇总**：按类型 / 管理单位 Count·Group By；自然语言提问如「进水闸 节制闸 各多少个」「有多少个闸门」直接给数并给分布。
3. **预案 / 规程文档入库与关联**：导入防汛调度预案、闸门安装规程等文本，自动**整句粒度切片**（约 420 字 / 重叠 60 字）并向量化，按条目名称自动建立关联；查询时同时返回参数与「该条目在预案中的调度/应用要求」。
4. **生成报告（doc / docx · 预览打印）**：查询结果一键生成结构化「小作文」（概述 / 相关条目 / 数量统计 / 类型释义 / 文档片段 / 结论与建议），可导出 `.doc`、`.docx`，并支持预览与打印（打印时可另存 PDF）。
5. **PDF 转 Word 工具**：解析 PDF 文本流、保留段落与顺序，输出 `.doc` + `.docx`；扫描件无文本层时提示改用 OCR 入库。
6. **类型知识库**：内置水工建筑物类型（进水闸/节制闸/泄洪闸/倒虹吸/渡槽/跌水…）的「定义 · 含义 · 作用」，向量化入库，可被自然语言检索命中。
