- 注入解析 `APP_VERSION` 末段数字的函数：`last % 2 === 0 → internal`，否则 `public`；全局 `RELEASE_CHANNEL` + `window.SHUILI_RELEASE_CHANNEL` / `window.PERC_RELEASE_CHANNEL`。

- `node --check` 双端全过。该机制**版本号一升即自动切换通道**，无需人工记通道（铁律-诊断同源：版本号读 `APP_VERSION`）。

- `strip_internal.py <canonical> --restore`：从 `.strip_backup/<product>/`（assets 外）还原 `kb_building_seed.js` / `ai_seed.js` 真实版。
- `bump_version_v350.py`：3.49→**3.50**、1.25→**1.26**、gujian 3.7 不变；构建日期 **2026-09-03**；`version.json` + app.js + 全部 webroot（`sync_all_mirrors.py --real/--check`）+ 构建脚本硬编码串 + 小程序基线全量提升。
