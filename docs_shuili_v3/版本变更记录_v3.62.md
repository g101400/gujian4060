# 版本变更记录 v3.62（2026-09-08，内部测试包）

> 配套：感知 v1.38；古建 v3.7.6（同轮五条问题修复）。
> 性质：**用户复检五条问题修复**（隐藏/收藏、照片链路、deb 导出）。
> 产物：`APK归档/`（真机验证测试包）。

## 一、本次需求（用户五条）

1. ① 隐藏/收藏子菜单增加二次确认（防误点）。
2. ② APK 导入 ovkmz 后照片「列表看着有、点击灯箱空白」。
3. ③ APK 导入 ovkmz 照片显示不正常（占位符/错图/不显示）。
4. ④ deb 端筛选后导出照片提示「没有可导出的照片」且不显示数量。
5. ⑤ deb 端隐藏/收藏按钮图标不明显。

## 二、核心改动

### E1 隐藏/收藏二次确认（①）

- 新增 `menuTitleOf(k)`（buildMenu 时写 `window.__menuTitle[it.k]=it.t`）；hideSubMenu 与 toggleFavMenu 均改为 `ask()` 确认后执行。
- 收藏按钮图标改 SVG 后不能再 textContent 覆盖，fav 点击回调改带 done 回调。

### E2 照片灯箱空白根治（②）

- **真因**：`photoFullSrc` 走 `Android.readPhoto(p.file)` 回传整张原图 base64（1.5M 照片 ≈ 2M 字符串），超过 WebView JS↔Java 桥 Binder 传输上限返回空串 → 灯箱空白（缩略图走 ensureThumb(320) 所以列表看着有）。
- **修复**：photoFullSrc 改取大缩略图 ensureThumb(1600)→(1024)→thumbPhoto(1024)→readPhoto→浏览器相对路径→p.data 多级兜底；appLightbox 加 `img.onerror` 自动退回缩略图并 toast 提示。三应用同步。

### E3 导入照片落盘归位（③）

- 修复 escapeJson **漏转义单引号回归**（v3.31 曾修，上轮重写时漏掉）——含 `'` 的 KML/文件名会截断 `window.onXxx('...')` 报 script error；三产品 LargeFileManager 补 `case '\''`。
- 新增原生桥 `linkPhotoToBuilding(buildingId, srcRel, name)`，mergeImported 把导入的临时照片 `photos/import_<ts>/pic_N.jpg` 归位到 `photos/<建筑物id>/pic_N.jpg`（与「添加照片」落盘规范一致），导入结果上报「照片落盘成功 X 张 / 异常 Y 张」。

### E4 deb 筛选后导出照片（④）

- doExportPhotos 收集照片由 `if (!p.file) return;` 改为 `if (!p.file && !p.data) return;`（浏览器端 ovkmz 导入的照片只有 data、没有 file）。
- 遍历源改为「筛选激活时 filteredList()，否则 BUILDINGS」，支持筛选后导出。
- openExportPhotos 顶部加统计条「当前共有 N 个建筑物带照片，合计 M 张可导出（已按当前筛选结果统计）」，管理所单选后显示「（X 张）」。

### E5 deb 图标内联 SVG（⑤）

- **真因**：deb 浏览器壳系统缺 emoji 字体 → 🙈/★ 渲染极淡/缺失。
- **修复**：菜单行图标改内联 SVG（eye-off 24x24 stroke=currentColor；星形 fill=currentColor/none），无字体依赖、四端一致。
