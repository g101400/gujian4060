## 一、本批实际改动（全部在感知 v1.48）

### 1. 内置「水工建筑物底图种子」`water_data.js`
- 现象（上批遗留）：感知 App 的「水工建筑物层」默认是**空库**，必须手工导入水利导出的 ovkmz 才有数据，
  首次安装打开是空白，不便于比对与跨层查询演示。
- 处理：新增 `assets/water_data.js`（`window.WATER_BUILDINGS`，**557 条**水工建筑物，
  含名称／管理所／渠道／类型／桩号等参数／经纬度，其中 407 条含坐标），数据源自水利 App 的建筑物骨干种子。
  1. 感知 `load()`：**首次安装**（本地库键 `perc_water_v2` 为空）时自动把内置种子播种进建筑物层并固化；
     此后一律以本地库为准，增删改不回灌。
  2. 新增「**重新播种内置建筑物种子**」（菜单「水工建筑物层」+ 数据层切换面板按钮），
     可在清空后一键恢复；**清空不会自动重建**（种子不回流）。
  3. 种子记录 id 统一为 `w1…w557`，与「建筑物层内新建 id 用 `w*` 前缀」既有约定一致，不与感知设备 `p*` 撞号。
- 与既有语义不冲突：两层仍**完全独立**，种植入的只是建筑物层；感知设备库 `perc_map_v2` 逐字节不变（回归断言覆盖）。

### 2. 脱敏与门禁扩展
- `strip_internal.py` / `make_public_pwa.py` 的脱敏清单加入 `water_data.js → water_data.demo.js`

- `sync_all_mirrors.py` 的 `CORE` 核心文件清单加入 `water_data.js`（镜像一致性强制校验）。
