# 智能 App 网盘同步规则（约定）

> 本规则约定：每次完成版本更新后，必须执行**两份同步**——① 分发同步（可部署文件入网盘并分类），② 备份同步（项目文件入网盘备份）。
> 目的：便于查找、便于分享、区分公开/内部、且每次发版自动留痕。

---

## 〇、网盘目标目录结构（我的资源/智能app）

```
我的资源/智能app/
├── 水利一张图/
│   ├── 公开版/ 3.49/        # 单数版，剥离真实数据+空密钥，标「公开测试版」
│   │   ├── Android/  iOS/  UOS/  Windows/
│   └── 内部版/ 3.48/  3.50/ # 偶数版，含真实数据+真实密钥，标「内部版」
│       ├── Android/  iOS/  UOS/  Windows/
├── 古建景点打卡/
│   ├── 公开版/ 3.7/         # 恒 3.7，AI 密钥置空
│   └── 内部版/ 3.6/  3.7/   # 恒 3.7，AI 密钥真实
├── 水利感知项目一张图/
│   ├── 公开版/ 1.25/
│   └── 内部版/ 1.24/  1.26/
├── 版本说明文档/            # 每次发版追加的版本说明（见《版本说明文档.md》）
├── 网盘同步规则/            # 本规则文件
└── 项目备份/               # 源码/工程文件按日期备份
    └── YYYYMMDD/
```

目录层级：**产品 → 通道 → 版本 → 平台**（版本级用于同一通道多版本共存时便于查找；文件名本身已带版本号，不会冲突）。
平台子目录约定：Android=*.apk；iOS=*_可托管.zip；UOS=*_{amd64,arm64,loongarch64,mips64el}.deb；Windows=*_Setup.exe + *_Setup.msi。
完整落点映射见《网盘文件落点清单.md》。

## 一、同步 A —— 分发同步（可部署文件）

**触发**：每次出包完成且 `verify_leakfree.py` 复扫通过后。

**步骤**：
1. 取当次归档：`APK归档/四端安装包_<日期>_v<奇>_pub/`（公开）与 `..._v<偶>_int/`（内部）。
2. 按「〇」结构，将文件按 产品 / 通道 / 平台 分类放入 `我的资源/智能app/` 对应子目录：
   - 水利一张图 → 公开版/内部版
   - 古建景点打卡 → 公开版/内部版（仅密钥差异）
   - 水利感知项目一张图 → 公开版/内部版
3. 同步更新 `我的资源/智能app/版本说明文档/版本说明文档.md`（追加变更记录、更新清单）。
4. 公开版文件可在网盘创建分享链接对外分发；内部版**不创建公开分享**，仅单位内部可见。

**公开/内部区分铁律**：
- 落入「公开版」的文件必须来自 `_pub` 归档且经 `verify_leakfree.py` 核验 `sk-or-v1=0`、含「演示」标记。
- 落入「内部版」的文件来自 `_int` 归档，含真实坐标与密钥，严禁外发分享。
- 古建公开版与内部版文件名相同，**仅靠 `ai_seed.js` 密钥是否置空区分**，分发前务必复扫确认。

---

## 二、同步 B —— 备份同步（项目文件）

**触发**：与同步 A 同时（每次版本更新后）。

**步骤**：
1. 将工程源文件同步至 `我的资源/智能app/项目备份/YYYYMMDD/`：
   - `android-build/`（各产品 assets、构建脚本）
   - `native-shell/`（deb/msi/exe/ios 构建脚本与 webroot）
   - `travel/android/`（古建 APK 工程）
   - 策略文档 `双通道奇偶发版与信息脱敏策略.md`、台账、本规则文件
2. 以日期目录隔离，便于回滚；同名采用副本名而非覆盖。
3. 备份仅作存档，不参与对外分发。

---

## 三、每次发版的强制前置门禁

出包→同步前必须全部通过，否则不得同步：
1. **剥离校验**：`strip_internal.py --public` 已对公开归档执行，三个敏感载体（kb/data/ai_seed）均为演示/空密钥。
2. **真抽取复扫**：`verify_leakfree.py <归档路径>` 退出码 0，输出 `real=0`（ar 解析 deb、解 APK/zip、流抽 exe/msi 内 ai_seed.js，勿用 `unzip` 解 deb——会假阴性）。
3. **版本门禁**：`version.json` 末位奇偶与通道一致；关于页/启动 toast/功能介绍三处标注正确。
4. **内部版源还原**：出包后 5 处真实密钥源已还原为真实密钥（内部版不受影响）。

## 五、操作清单（每次发版照此执行）

- [ ] 出包完成（公开 `_pub` + 内部 `_int`）
- [ ] `verify_leakfree.py` 两归档均 PASS
- [ ] 同步 A：分类放入 `我的资源/智能app/<产品>/<通道>/<平台>/`
- [ ] 同步 A：更新 `版本说明文档/版本说明文档.md`
- [ ] 公开版按需创建分享链接；内部版不分享
- [ ] 同步 B：工程源入 `项目备份/YYYYMMDD/`
- [ ] 内部版真实密钥源已还原
