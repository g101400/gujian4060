# 网盘文件落点清单（复制映射表）

> 本清单把本地 `APK归档/` 中各可部署文件，逐一映射到网盘 `我的资源/智能app/` 的目标路径。
> 用法：① 在网盘按「目录结构」建好文件夹；② 按本表把文件复制/上传到对应位置；③ 公开版目录按需创建分享链接。
> 基线：水利 3.48 / 古建 3.6 / 感知 1.24 起（双通道时代，覆盖 v348 / v349_pub / v350_int 三包）。
> 更早版本（v33–v347，前双通道时代）默认不入网盘，如需纳入请另行指定。

---

## 一、网盘目录结构

```
我的资源/智能app/
├── 水利一张图/
│   ├── 内部版/ 3.48/ 3.50/        # 各含 Android/ iOS/ UOS/ Windows/
│   └── 公开版/ 3.49/
├── 古建景点打卡/
│   ├── 内部版/ 3.6/ 3.7/
│   └── 公开版/ 3.7/               # 与内部版同名，唯一区别 AI 密钥置空
├── 水利感知项目一张图/
│   ├── 内部版/ 1.24/ 1.26/
│   └── 公开版/ 1.25/
├── 版本说明文档/                   # 版本说明文档.md
├── 网盘同步规则/                   # 网盘同步规则.md（本规则）
└── 项目备份/ YYYYMMDD/             # 工程源按日期备份（同步 B）
```

平台子目录约定：Android=`*.apk`；iOS=`*_可托管.zip`；UOS=`*_{amd64,arm64,loongarch64,mips64el}.deb`；Windows=`*_Setup.exe`+`*_Setup.msi`。

## 六、复制顺序建议（便于查找/分享）

1. 先建「〇」全部目录（产品→通道→版本→平台）。
2. 按二~四逐产品把文件拖入对应版本/平台目录。
3. 公开版（水利3.49、感知1.25、古建3.7）目录创建分享链接对外分发；内部版（含真实坐标+密钥）**不分享**，仅单位内部可见。
4. 同步 A 完成后，把 `版本说明文档/版本说明文档.md` 与 `网盘同步规则/网盘同步规则.md` 存入对应目录。
5. 同步 B：把工程源按 `项目备份/YYYYMMDD/` 备份。
