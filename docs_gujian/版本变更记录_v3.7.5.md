## 二、核心改动

### E1 写备忘录 / 我的备忘录（承接上轮补的入口，本轮随版发布）

- 上轮已在 gujian app.js 补齐双配置 `nmTravelCfg`(游记/gujian_notes_v1) + `nmMemoCfg`(备忘录/gujian_memos_v1) 与 `nmGo(kind, act)` 分发，写游记/写备忘录/我的游记/我的备忘录均经 nmGo 点击并 try/catch 兜底，杜绝「运行错误:script error」。
- 所见即所得编辑器与写游记同源；备忘录独立存储、独立列表入口。

### E2 知识库导出自定义（kbExport，共享模块三应用同步）

- 文件名默认 `知识库_YYYYMMDD.fmt` 可改；可填保存文件夹（安卓 `saveBlobTo` 落 `Download/<folder>/`，Win/统信/网页回退系统下载目录）。

### E3 古建导出统一命名弹窗（本版新补，补齐第③点）

- 新增 `gjExpDialog`（自定义文件名 + 保存文件夹，交互与 kbExport 一致）与 `gjSaveOut`（安卓 saveBlobTo / 网页 <a download> 双通道）。
- **导出古建表格(CSV)**、**导出数据(JSON)** 改为弹窗保存；**导出 ovkmz** 增加文件名自定义（大文件走原生 exportKmz 流式，落 `Download/古建景点打卡/`）。
