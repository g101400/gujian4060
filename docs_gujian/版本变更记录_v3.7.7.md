## 二、核心改动

### E1 菜单收藏/隐藏统一 API（v3.7.7，作用域内补齐）

- 补齐作用域内 `menuTitleOf / getFavMenus / setFavMenus / toggleFavMenu` 局部函数声明，杜绝 getFavMenus 未定义导致整个菜单不渲染（被 window.onerror 吞成「运行错误:script error」）。
- 收藏（快捷常用）与隐藏保留二次确认；收藏数据与长按收藏共用同一份（`gujian_favorites_v32`）。

### E2 知识库智能化内核（菜单「智能化内核」，`kb_core.js`）

1. 智能模糊检索（错字/简写/别名，带相似度排序，可就地提问）。
2. 提示词生成器（6 套业务模板，可复制或一键提问）。
3. AI 记忆 · Hermes（对话记忆查看/清空 + 经验沉淀，后续问答自动引用）。
4. 存疑反向查询（反查出处 + 数值冲突待核实清单，可联网核实）。
5. 强制联网开关（开启后强制走在线模型，断网明确报错，不再静默降级）。
- 菜单注入锚点：`groups.push({ g: "信息与帮助" ... })` 之前 concat KBCore 组。

### E3 安卓导入 ovkmz 自动定位与缩放

- 导入落库后 `map.invalidateSize()`（延迟 300ms 补一次）+ 自动 fitBounds 到导入要素范围（pad 0.2 / maxZoom 16）。

### E4 四端功能对照单与版本变更

- `openPlatformCompare()` rows 头插本版条目（列序 安卓/Win11/UOS/iOS）；openChangelog 头插 3.7.7 段。
