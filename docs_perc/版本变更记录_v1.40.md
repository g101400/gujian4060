## 二、核心改动

### E1 菜单 script error 根治

- IIFE 作用域内补齐 `getFavMenus / setFavMenus` 局部函数声明，根治「getFavMenus is not defined」导致菜单整体不渲染；收藏/隐藏保留二次确认。

### E2 安卓 ovkmz 导入显示修复

- 导入落库后 `map.invalidateSize()`（延迟 300ms 补一次）+ 自动 fitBounds（pad 0.2 / maxZoom 16）。

### E3 知识库智能化内核（菜单「智能化内核」，`kb_core.js`）

1. 智能模糊检索（错字/简写/别名，相似度百分比，可就地提问）。
2. 提示词生成器（6 套业务模板，可复制或一键提问）。
3. AI 记忆 · Hermes（对话记忆查看/清空 + 经验沉淀自动引用）。
4. 存疑反向查询（反查出处 + 数值冲突待核实清单）。
5. 强制联网开关（强制走在线模型，断网明确报错 + 连通性自检）。

### E4 内部版防泄密（方案二）

1. 内部 PWA 数据 AES-256-GCM 加密为 `secure/dat.enc.js`，明文文件下线（404 验证）；启动口令门（3305），口令不在代码明文存储。
2. 内部 PWA 部署到公开仓库 Pages：https://g101400.github.io/ganzhi-yitu5090-sec/
3. 内部版（偶数号）Android / Win11 / 统信 UOS 启动口令门；公开版自动放行。
4. GitHub 升级内部渠道切至公开 sec 仓 `ganzhi-yitu5090-sec`，免登录检测与下载。
