# 版本变更记录 v1.36（2026-09-07，内部通道）

## 一、本次需求

1. 内部通道补发与 v1.35 同源的功能版（公开 v1.35 / 内部 v1.36 奇偶并行）。

## 二、核心改动

### E1 与 v1.35 同源功能（内部通道）

- 知识库管理导出 md/txt/html 自定义文件名（默认 `知识库_YYYYMMDD.md/.txt/.html`）+ 自选保存文件夹，共享模块 kbExport 三应用同步。
- 其余导出（设备表格 / 照片 / ovkmz / ovobj / obj / 升级备份）自定义文件夹与文件名逐一核查保持；各子菜单防「运行错误:script error」冒烟回归。
- 信息与帮助（功能介绍 / 版本变更 / 四端功能对照单）更新至 v1.36。

### E2 ovkmz 导入/导出兼容修复（随版）

- 导入兼容奥维原装 ovkmz（BOM / TAB 分隔符差异 + 照片附件）；导出格式与奥维原装一致。

### E3 GitHub 升级链路落地（随版）

- 五仓库统一改名（方案C）；各仓按版本建 Release/tag（四平台安装包资产）；App 设置新增「通过 GitHub 升级」，按渠道查询对应仓库 Release 并下载。
