# 四端对照表 · 感知「水工建筑物数据层」（v1.48 · 2026-09-11）

> 本轮只改感知 App；水利 v3.70 / 古建 v3.7.10 不动。四端实现形态沿用既有约定：
> **Android / Win11 / 统信 UOS = 原生应用**（性能优先）；**iOS = PWA + 静态 HTTPS**。

## 1. 新增能力在四端的落地形态

| 能力 | Android（APK） | Windows 11（MSI/EXE） | 统信 UOS（deb） | iOS（PWA） |
|---|---|---|---|---|
| 数据层切换（设备/建筑物/全部） | 顶部按钮 + 筛选面板 chip | 同左 | 同左 | 同左 |
| 导入水工建筑物（ovkmz/kmz/kml） | 原生 `pickFiles` 选择 → 原生导入桥 | 浏览器文件选择 + 本地 HTTP 服务 | 同 Win | 浏览器选择 |
| 导出水工建筑物（ovkmz） | 原生保存到 `Download/水利工程一张图/` | 浏览器下载 | 浏览器下载 | 浏览器下载 |
| 跨层周边问答 | 本地计算（`map.distance`） | 同左 | 同左 | 同左 |
| 结果导出 CSV | 原生 `saveBlobFile` → Download | 浏览器下载 | 浏览器下载 | 浏览器下载 |
| 照片查看/编辑（photo_gesture） | 手势/长按菜单 | 鼠标拖拽缩放 | 鼠标拖拽缩放 | 触摸捏合 |
| 内部版口令 | 首启口令门（AES-256-GCM + PBKDF2） | 同左 | 同左 | 数据整体 AES 加密托管 |

## 2. 存储键（四端一致）

| 键 | 内容 | 说明 |
|---|---|---|
| `perc_map_v2` | 感知设备库 | 沿用 v1.46 及以前，老数据自动升级，首启行为不变 |
| `perc_water_v2` | 水工建筑物层 | 新增；**只经「导入水工建筑物」写入** |
| `shuili_settings` | 其中 `.scope ∈ {device,water,all}` | 数据层偏好持久化，默认 `device` |
| `perc_memos_v1` / `shuili_xfer` / `org_levels` 等 | 不变 | — |

> 升级数据导出/导入（设置 → 升级数据导出）会自动包含 `perc_water_v2`（`upLsKeys()` 逐键收集），
> 因此跨端搬运建筑物层无需额外操作。

## 3. UOS 架构对照（沿用固化表，本轮未变）

| CPU | 架构包 |
|---|---|
| 龙芯 3A3000 / 3A4000 | `mips64el` |
| 龙芯 3A5000 及以上 | `loongarch64` |
| 飞腾 FT2000 / 鲲鹏 | `arm64` |
| 其余（x86_64） | `amd64` |

deb 铁律：`ar` 成员名空格填充（绝不 NUL）/ `mode` 100644 / `data.tar` 用 xz / `verify_myml_ar.py` 通过才交付。

## 4. 通道

- 本轮为**内部（偶数）通道**：感知 **v1.48**（水利 3.70 / 古建 3.7.10 保持）
- 公开（奇数）通道重出需先 `strip_internal.py --public` 脱敏，再推 pub 仓 Pages/Release（本轮未做）
