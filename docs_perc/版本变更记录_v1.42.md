# 版本变更记录 v1.42（2026-09-09，内部版）

与水利 v3.66 / 古建 v3.7.8 同步。本版核心：**水利/感知 内部版新增「访问口令保护」**（公开版免密）。

## 新增
1. **内部版访问口令保护（默认口令 = 开发者分机号 3305）**
   - 安装 / 首次使用弹出口令门，须输入正确口令方可进入；口令错误拒绝进入。
   - 口令框内置「保存口令，下次不用输入」选项（默认勾选，可取消——取消后每次启动都要验证）。
   - 设置菜单新增「🔑 修改口令」「❓ 忘记口令」子菜单（仅内部版显示）：
     - 修改口令：先验证当前口令 → 输入新口令（≥4 位）+ 确认 → AES-GCM 加密后落本地，下次免输；
     - 忘记口令：明确提示「默认口令即开发者分机号 3305；若自定义后遗忘，请联系开发者（分机 3305）重置」。
2. **iOS 内部加密 PWA**（另见加密包）：数据以 AES-256-GCM（PBKDF2-SHA256 12 万次迭代）整体加密，启动口令 3305 即开发者分机号；口令不在代码中明文存储。
3. **防双重输入**：数据加密版中，secure_gate 解密数据后应用内口令门自动放行（同一会话），避免连输两次口令。

## 说明
- 口令仅锁「内部版（偶数版号）」，公开版（奇数版号，演示数据）自动放行、无需口令。
- 古建为公开应用，不启用口令。
