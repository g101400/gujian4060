## 一、本次变更范围

1. **发行前预生成知识库**：构建期生成 `assets/kb_building_seed.js`（`window.KB_BUILDING_SEED`，1125 条监测设施，含管理所/站/类型/渠道/子系统/参数/照片/坐标），随 APK/DEB/MSI/EXE/PWA 全平台安装包内置；`ai_module.js init()` 时 `mergeSeed()` 按 buildingId 去重合并进本地 KB，不覆盖用户后续增改。安装即有知识库，无需联网。
2. **智能AI × 知识库查询融合**：与水利/古建同引擎——先查本地 KB（结果标注 **🔒本地**），未命中且允许联网再走大模型（标注 **🌐在线**），未命中且离线给友好提示。全程 `Promise resolve` 不 reject、异常转友好结果，根治偶发「运行错误: script error」。
3. **知识库查询加确认按钮**：知识库管理中的查询需点击确认后执行，防误触。
4. **知识库网页入库**：支持读取普通网页 / 微信公众号文章 / 微博，抽取正文沉淀为 KB 条目；受目标站跨域限制失败时提示改用复制粘贴入库。
5. **智能更新补丁可编辑**：补丁预览由只读文本改为**可编辑输入框**，应用前可逐字段修改。
6. **四平台同步重建**：Android APK / Win(WebView2 MSI+EXE) / UOS(mips64el deb) / iOS PWA 全部重出 v1.17 包。
