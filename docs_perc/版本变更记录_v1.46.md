## 一、修复（与水利 v3.70 同源）
1. **口令门提示去掉具体口令**：`secure_boot.js` 不再拼接 `DEV_EXT`，只提示「默认口令即开发者分机号 · 输错无法进入」。
2. **本地导入/导出不再误报「非 WiFi 网络」**：新增 `confirmLocal()`，<100MB 静默执行，≥100MB 弹「操作提示 / 文件大小…耗时较长，是否继续？」；真网络操作（手机互传下载）保留原警告。
3. **「管理处」两面不一致修复**：`orgStore()` 首启补齐 5 个处且尊重用户后续增删改；筛选栏与「组织与类型管理」同源；筛选栏新增 ＋添加 / ✎改名；`FIELD_ALIAS` 新增 `guanchu`/`ju` 独立别名，杜绝「管理处」列导入串到管理所。

## 二、公共模块回灌（重点）
感知端长期滞后于水利的三个共享模块，本版一次性对齐：

| 模块 | 修复内容 |
|---|---|
| `kb_rag.js` | 知识库切片升级为**整句优先**（段落 → 句末标点 → 逗号级 → 极端硬切兜底），重叠按整句回溯，绝不在句中断开 |
| `ai_module.js` | **保存前先切片再落盘**（`kbSave` 统一写入口 + chunks/签名缓存，正文变更才重切）；入库即用已存切片向量化 |
| `ovobj_bridge.js` | `exportOvobj(fileName)` 支持**自定义文件名**（此前忽略入参，导致感知端「导出 ovobj 文件名可编辑」失效） |

> 这三项在感知 v1.31 的版本变更里曾被标为 ✅，实际未落地。本版真正落地，并新增 `sync_all_mirrors.py` **跨产品公共模块 md5 门禁**防复发。
